# PPT 生成项目演示

根据 Markdown 自动生成 PowerPoint。

## 项目目标

- 输入 Markdown 或文本提纲
- 自动拆分为 PPT 页面
- 生成可编辑的 `.pptx` 文件

## 第一版功能

- 支持标题页
- 支持内容页
- 支持段落和列表
- 支持命令行导出

## 后续计划

- 增加主题模板
- 支持图片
- 支持表格
- 支持网页上传生成
