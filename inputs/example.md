# PPT 生成项目演示

根据 Markdown 自动生成可编辑 PowerPoint。

## 项目目标

- 输入 Markdown、文本提纲或 WPS/Word 文档
- 自动拆分为 PPT 页面
- 支持主题、图片、表格和布局控制
- 导出可编辑的 `.pptx` 文件

<!-- layout: image-right -->
## 图片页面

- 支持 Markdown 图片语法
- 图片会自动按比例缩放
- 可选择图片在左或在右
